
## API Backend start
1. Go to BE
``` bash
cd api
```
2. Run
``` bash
npm run dev
```

## Frontend
Build
``` bash
npm install
```
Run
1. Go to FE
``` bash
cd client
```
2. Run
``` bash
npm start
```

## Backend client
Compile backend services
``` bash
npx run build
```
Run
``` bash
npm run start
```
